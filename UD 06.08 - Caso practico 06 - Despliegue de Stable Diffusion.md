# Stable Diffusion

## Paso 1: Obtención del código

Primero, es necesario obtener los archivos de configuración del proyecto.

- **Comando** :
    Bash
    “git clone https://github.com/AbdBarho/stable-diffusion-webui-docker.git”

## Paso 2: Preparación y descarga de modelos

Antes de ejecutar la interfaz, se deben descargar los componentes y modelos necesarios del sistema

```
“docker compose --profile download up –build”
```
<img width="1366" height="768" alt="Captura6 8 2" src="https://github.com/user-attachments/assets/69aa1327-0f74-447c-a9e9-d1602cfe6f4b" />


## Paso 3: Ejecución de la Interfaz (UI)

Una vez finalizada la descarga, puedes lanzar el sistema eligiendo el perfil de interfaz que mejor se
adapte a tu hardware.

- **Comando general** :
    Bash
    docker compose --profile [UI] up --build
- **Ejemplo para CPU (sin tarjeta gráfica potente)** : Si no dispones de una GPU compatible,
    utiliza el perfil auto-cpu:
    Bash
    docker compose --profile auto-cpu up --build

## Paso 4: Acceso al sistema

Una vez que el contenedor esté en marcha, podrás utilizar Stable Diffusion abriendo tu navegador
web:

- **URL** : [http://localhost:7860/](http://localhost:7860/)
