 # UD 04. Caso práctico

 # 02 - Creando imagencon APP ejemploDocker en Node

## Paso 1: Preparación del entorno**

Primero, crea un directorio para el proyecto (por ejemplo, Caso4-2) y descarga en él los archivos de la aplicación (debes tener los ficheros “package.json, yarn.lock” y las carpetas “src” y “spec”)

<img width="1366" height="768" alt="Captura4 1" src="https://github.com/user-attachments/assets/aab15e45-0731-47dd-85aa-2de844ba992a" />


## Paso 2: Configuración del Dockerfile**

Crea un archivo llamado Dockerfile en ese mismo directorio con lo siguiente;

“FROM node:12-alpine [cite: 55] WORKDIR /app [cite: 56] 

COPY . . [cite: 57, 58] 

RUN yarn install --production [cite: 59] CMD ["node", "src/index.js"] [cite: 60]”

<img width="1366" height="768" alt="Captura4 2" src="https://github.com/user-attachments/assets/e0937933-cae0-4a5f-9b03-eef0fecc1caf" />


 ## Paso 3: Construcción de la imagen** Abre tu terminal y ejecuta el comando

“docker build -t sampledocker ./”

<img width="1366" height="767" alt="Captura4 3" src="https://github.com/user-attachments/assets/285c8b66-1191-4bab-b746-5a921c98473c" />

despues ejecuta el contenedor 

“docker run -dp 3000:3000 sampledocker”

Para comprobar que la aplicación está funcionando correctamente, abra un navegador web y acceda a la siguiente dirección:

**URL:** http://localhost:3000
