# UD 05.05 - Caso practico 03 - Acelerando juegos de prueba

# con tmpfs

**Preparación del Contenedor MySQL**

comando para crear un contenedor:

“docker run -d --rm --name mysqlsintmpfs -p 3306:3306 \”
“-v /home/sara/dump.sql:/docker-entrypoint-initdb.d/dump.sql \”
“-e MYSQL_ALLOW_EMPTY_PASSWORD=TRUE \”
“-e MYSQL_USER=sara-e MYSQL_PASSWORD=sara21 \”
“mysql:5.6”

Ejecutaremos de forma optimizada con tmpfs

“docker run -d --rm --name mysqlcontmpfs -p 3307:3306 \”
“-v /home/sara/dump.sql:/docker-entrypoint-initdb.d/dump.sql \”
“--tmpfs /var/lib/mysql:rw,noexec,nosuid,size=1024m \”
“-e MYSQL_ALLOW_EMPTY_PASSWORD=TRUE \”
“-e MYSQL_USER=sara -e MYSQL_PASSWORD=sara21 \”
“mysql:5.6”

probaremos su rendimiento de la siguiente manera:

entramos al contenedor:
“docker exec -it mysqlcontmpfs bash”

entramos al cliente MySQL:
“mysql -u root”
