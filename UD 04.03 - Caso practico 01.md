# UD 04.03 - Caso practico 01 - Creando imagen Ubuntu con nano**

## El primer paso es crear un archivo de texto llamado Dockerfile con lo siguiente:

“FROM ubuntu “

“RUN apt update && apt install -y nano && apt purge-auto-remove && apt clean && rm -rf /var/lib/apt/lists/\*” “
CMD /bin/bash”
<img width="1366" height="768" alt="Captura4 3 1" src="https://github.com/user-attachments/assets/b9f81471-1005-4037-8198-11627af72df5" />


 ## Una vez guardado el archivo en un directorio, se procede a construir la imagen: 
“docker build -t ubuntunano ./ ”

![]<img width="1365" height="768" alt="Captura4 3 3" src="https://github.com/user-attachments/assets/35955250-097a-4dae-81e4-7d0b3bd88912" />


 ## Finalmente, se debe comprobar que la imagen se ha creado correctamente y que el editor funciona 
“docker run -it ubuntunano”
