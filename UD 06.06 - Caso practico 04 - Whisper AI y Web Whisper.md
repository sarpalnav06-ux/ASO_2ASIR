# Web Whisper

2. Pasos previos: Preparación de ficheros
Antes de lanzar los contenedores, es necesario preparar los archivos de configuración a partir de las
plantillas de ejemplo proporcionadas en el repositorio del proyecto

**Configurar Docker Compose** : Copia y renombra el archivo de ejemplo para crear el fichero de
configuración principal:

“cp example.docker-compose.yml docker-compose.yml”

Configurar variables de entorno

“cp example.env .env”
<img width="1366" height="768" alt="Captura6 6 1" src="https://github.com/user-attachments/assets/37c9eb21-fb1b-4327-a480-8a00b24aefc3" />


Ejecuta el siguiente comando en la terminal:

“docker compose up --build -d”

## Verificación y funcionamiento

Tras ejecutar el comando, Docker descargará las dependencias necesarias (como bibliotecas de

Python y compiladores de C++) y compilará los servicios.

- **Proceso de construcción** : Verás que se descargan imágenes base como gcc:bullseye
    para compilar los componentes necesarios de Whisper.
- **Uso** : Una vez finalizado el proceso, podrás acceder a la interfaz web
