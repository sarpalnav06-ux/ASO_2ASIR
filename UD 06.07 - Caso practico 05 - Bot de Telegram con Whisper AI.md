UD 06.07 - Caso practico 05 - Bot de Telegram
con Whisper AI
Pasos previos: Configuración en Telegram
Antes de trabajar con Docker, es necesario crear el bot y obtener las credenciales necesarias:

Crear el Bot : Habla con el @BotFather en Telegram para generar un nuevo bot y obtener
tu TELEGRAM_BOT_TOKEN.
Obtener IDs de usuario/grupo : Debes conocer el ID del chat (usuario o grupo) donde
operará el bot para autorizarlo en la configuración.
- Los IDs de usuarios son números como 1234567890.
- Los IDs de grupos llevan un menos delante: -
Preparación del entorno
Sigue estos comandos para preparar los archivos en tu máquina local:

Obtener el código :
“git clone https://github.com/sergarb1/telegram-bot-whisper-cpp”
Configurar variables de entorno : Edita el fichero llamado env e introduce los siguientes valores
obligatorios:

TELEGRAM_BOT_TOKEN : El token obtenido de BotFather.
ALLOWED_CHAT_IDS : Los IDs autorizados separados por comas (o * para permitir a
todos).
WHISPER_MODEL : Elige el modelo (tiny, base, small, medium, large). Se recomienda
usar como máximo el small para pruebas.
AUDIO_LANGUAGE : Idioma del audio (puedes dejarlo en auto
iniciar el sistema
“docker compose up --build -d”
