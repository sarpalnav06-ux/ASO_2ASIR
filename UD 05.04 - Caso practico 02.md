**Imagen de HAProxy**

En el directorio haproxy, cree un Dockerfile basado en haproxy:1.7 que incluya el

archivo de configuración haproxy.cfg

“cd ../haproxy”
“ docker build -t mihaproxy”

**Paso 2: Configuración de Red y Servidores Apache**

crearemos la siguiente red:
“docker network create balanceo”

lanzaremos los contenedores apache:
“docker run -d --name ap01 --network balanceo miapache01”
“docker run -d --name ap02 --network balanceo miapache02”

**Paso 3: Lanzamiento del Balanceador HAProxy**

Crearemos el contenedor del balanceador vinculándolo a la red y pasando las variables de entorno
que definen a qué servidores redirigir el tráfico

```
“docker run -d --name ha01 --network balanceo -p 8080:80 \ “
“-e 10.2.206.10=ap01 \ “
“-e 10.2.206.11=ap02 “\
“-e APACHE_EXPOSED_PORT=80 \ mihaproxy”
```
