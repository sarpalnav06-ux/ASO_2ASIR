## UD 06.04 - Caso practico 02 - Django con Docker Compose

## 1. Preparación de los Ficheros de Configuración

Antes de ejecutar Docker, es necesario crear tres archivos fundamentales en tu directorio de trabajo
para definir la imagen y el entorno
requirements.txt
Dockerfile
docker-compose.yml

## Puesta en marcha de docker:

para construir imagen
“docker compose build”
Levantar el sistema en segundo plano:
“docker compose up -d”

# Crearemos Django

“docker compose run web django-admin startproject ejemplodjango ”

# Configuramos base de datos:

editar el archivo ./codigo/ejemplodjango/settings.py
y cambia lo siguiente:
Busca la sección DATABASES y sustitúyela por:

- **ENGINE** : django.db.backends.postgresql
- **NAME** , **USER** , **PASSWORD** : postgres
- **HOST** : db (el nombre del servicio en docker-compose)
- **PORT** : 5432

## Reiniciamos y verificamos

docker compose down; docker compose up -d
