## Puesta en marcha de docker:

para construir imagen
“docker compose build”
Levantar el sistema en segundo plano:
“docker compose up -d”

# Crearemos Django

“docker compose run web django-admin startproject ejemplodjango ”
 <img width="1366" height="767" alt="Captura6 4 4" src="https://github.com/user-attachments/assets/c45cd2f9-e242-46b1-a5ee-c951dd7d803d" />

# Configuramos base de datos:

editar el archivo ./codigo/ejemplodjango/settings.py
y cambia lo siguiente:
Busca la sección DATABASES y sustitúyela por:

- **ENGINE** : django.db.backends.postgresql
- **NAME** , **USER** , **PASSWORD** : postgres
- **HOST** : db (el nombre del servicio en docker-compose)
- **PORT** : 5432
