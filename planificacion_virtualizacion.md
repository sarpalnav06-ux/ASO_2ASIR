# Planificación: Configuración de Virtualización

**Autor:** Grupo 2  
**Módulo:** Administración de Sistemas  
**Fecha:** Junio 2026  

---

## Objetivo

Configurar un entorno de virtualización y contenedores utilizando **Proxmox VE**, **Docker**, **Docker Compose** y **Portainer**.

---

## Tecnologías

| Tecnología | Uso |
|-----------|-----|
| Proxmox VE | Hipervisor para crear y gestionar VMs y contenedores LXC |
| Docker | Ejecutar aplicaciones en contenedores |
| Docker Compose | Desplegar aplicaciones multi-contenedor |
| Portainer | Gestionar Docker desde una interfaz web |

---

## Fases del Proyecto

| # | Fase | Descripción |
|---|------|-------------|
| 1 | Instalación Proxmox | Instalar Proxmox VE y configurar la red |
| 2 | Crear VM / LXC | Crear una máquina virtual o contenedor LXC con Ubuntu |
| 3 | Instalar Docker | Instalar Docker Engine dentro de la VM/LXC |
| 4 | Pruebas Docker | Ejecutar contenedores básicos |
| 5 | Docker Compose | Desplegar un stack multi-servicio |
| 6 | Portainer | Instalar Portainer y gestionar Docker desde el navegador |
| 7 | Documentación | Documentar el proceso y subir a GitHub |

---

## Requisitos de hardware

- CPU con virtualización activada (VT-x / AMD-V)
- 8 GB RAM
- 60 GB de disco libre
