# UD 06.05 - Caso practico 03 - Proxy Nginx y balenceo escalado

# con Docker Compose

1. Prepararemos de los Ficheros de Configuración:
./apache
    con dentro : **Dockerfile**
       FROM php:7.2-apacheCOPY index.php /var/www/html/
       index.php
./nginxproxy
    con dentro:
    **nginx.conf** el tráfico al host llamado apache en el puerto : Configura a Nginx para escuchar en el puerto **80 4000** y redirigir

Archivo docker-compose.yml
**Servicio apache** : Se construye desde el directorio ./apache y expone el puerto 80.

- **Servicio nginxproxy** : Usa la imagen oficial de Nginx, mapea el archivo nginx.conf
    local y depende del servicio apache. Mapea el puerto **4000** del anfitrión
2. Pondremos en marcha el sistema
“docker compose up -d”
3. escalaremos los servidores:
“docker compose up -d --scale apache=4”
